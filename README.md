# Kotoba no Tabi 🌸 · ことばの旅

A gentle little journey through Japanese reading, sounds, and handwriting.
Public and dependency-free at runtime.

**Live:** https://nihongo.kiwinokoto.fr

## Garden of hiragana

- A small storybook map, with one playable destination (the hiragana garden)
- All **46 basic hiragana** in **10 progressively unlocked rows**; previous rows stay accessible
- Animated brush-stroke order from AnimCJK, including replay
- Mouse, touch and stylus drawing with a faint guide, undo and clear
- A recognition quiz: correct answers collect characters and unlock the next row
- A small travel journal, spaced reviews (1, 3, 7, 14, 30 days) and gentle retry scheduling
- Optional Japanese speech via **device-installed browser voices**; the app explicitly reports when none is available
- Preserves the progress saved by the first V1 prototype, under the same localStorage key

**Crucial distinction:** The animation shows the reference stroke order, and drawing
counts self-reported *practice*. It is **not handwriting recognition**. The app does
not claim to judge the geometry, stroke direction, stroke order or correctness of a
drawn character. Mastery is awarded only by a recognition exercise. This is deliberate
until a carefully evaluated handwriting matcher exists.

## Run and test

No bundler, package install, database or server application required.

```bash
node --check assets/app.js
node --test tests/*.test.mjs
python3 tools/draw_landscape.py
python3 -m http.server 8787
```

Open http://localhost:8787/. Optional browser E2E checks can be run locally with
Chromium/Playwright; no Playwright or CI runner is required to serve the site.

intentional manual asset update, not at runtime. No image-generation search results
were incorporated directly into the public repository.

## Security, privacy and deployment

The static site is served in an isolated Nginx container on the personal VPS
through the existing Traefik `traefik_network` and Let's Encrypt resolver.
It collects no student profiles, has no database or analytics, and contains no
secrets. Ordinary web server / reverse-proxy access logs may record IP addresses.

Progress is **only in local browser storage**, not backed up or synced between devices.
Google Fonts are requested from Google by a visitor's browser. Do not commit
credentials, visitor progress, or private files.

Before deployment check canonical GitHub main, runtime commit, local state, tests,
AgentCtl `repo:Kiwinokoto/nihongo` and deployment/service/Docker leases. Never
force-push or change other applications. See [AGENTS.md](AGENTS.md) and
[BACKLOG.md](BACKLOG.md) for coordination and next work.
